# 第四專區歌唱比賽初賽｜報名表

國際獅子會300A-2區 2026-2027年度 第四專區歌唱比賽初賽，照紙本報名表做的線上版。

- 公開填表頁：index.html（RWD，手機、桌機都可用）
  - 第一步先選組別：合唱組／獨唱組／長青組／新人組，選好才出現表單
  - 新人組入會日期必填（民國年、月、日）；合唱組有 8 位團員名單欄（可跨分會，手機選填），總人數自動計算，超過 8 人請把多的名單寫在備註
  - 紙本沒有 Email 欄，為了寄確認信才加 Email 欄
- 後台：admin.html（公開頁沒有連結，第一次開要自設密碼；可按組別／分區篩選、匯出 CSV、標記已確認、刪除）
- 資料庫：Google 試算表「第四專區歌唱比賽報名表」分頁「報名表」（21 欄）
- 後端：Code.gs（只放在 Apps Script，不推上公開儲存庫）— 寫入試算表、自動寄確認信、信裡附上同一份確認文字
- 收到確認信代表「已收到報名」，不是「已通過資格審查」，各組資格與賽制以正式公告為準

待 Jimmy 確認後再補上頁面：初賽日期、地點、報名截止日、寄信帳號（目前先沿用 GST 攤位申請同一模式，部署帳號寄出）。
